# Unity Arabic Converter

A professional tool for converting and processing Arabic text in Unity applications.

## Features
- 🌐 Arabic text conversion
- 🔤 Character encoding support
- ⚡ Fast processing
- 🎨 Web-based interface

## Components
- `arabic-engine.js` - Core Arabic processing engine
- `arabic-characters.js` - Character mappings and utilities
- `bidi-engine.js` - Bidirectional text support
- `shaping-engine.js` - Text shaping for proper display
- `unicode-engine.js` - Unicode conversion utilities
- `analyzer.js` - Text analysis tools
- `batch.js` - Batch processing capabilities

## Installation

```bash
npm install
# or
yarn install
# or
pnpm install
```

## Usageggg

Open `index.html` in your browser to use the web interface, or integrate the JavaScript modules into your project.
